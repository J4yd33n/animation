# Animated Weather Control Panel

This project is a small interactive web experience that looks like a futuristic climate control interface. It combines HTML, CSS, and JavaScript to create a rotating circular control with animated weather states and a temperature display.

## What it does

- Rotates a central control dial when clicked
- Cycles through six scenes: sun, sunset, moon, clouds, storm, and snow
- Updates the displayed temperature in both Celsius and Fahrenheit
- Changes the visual mood of the landscape with dynamic gradients, sky colors, and weather imagery
- Uses SVG artwork and CSS styling to create a polished, animated interface

## Project structure

- `index.html` – the page structure and layered SVG scene
- `style.css` – the visual styling, layout, and animation effects
- `main.js` – the interaction logic for rotation, weather transitions, and temperature updates

## How to run

Open `index.html` in a browser to view the project.

## Notes

This is a front-end demo built with vanilla JavaScript, so there are no dependencies or build steps required.
